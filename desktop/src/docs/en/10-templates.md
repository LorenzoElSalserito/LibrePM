# Chapter 10: Templates and Gallery 🎨

Don't want to build every project from scratch? The **Gallery** page offers a collection of pre-configured project templates that give you a head start.

---

## 🖼️ The Template Gallery

Click **"Gallery"** in the sidebar (the page title is **"Template Gallery"**). At the top you read "Project Templates — Start your project with a pre-configured structure." and below it you see a grid of cards.

### Filters
Above the grid you'll find two dropdowns and a counter:
*   **"All Categories"**: filter by category (e.g., PLANNING, PROJECT MANAGEMENT, NONPROFIT, GRANTS...).
*   **"All Complexity"**: filter by complexity — **Simple**, **Moderate** or **Advanced**.
*   The number of templates matching the filters (e.g., "11 templates").

The 🔄 **Refresh** button in the top bar reloads the list.

### Template Cards
Each card shows:
*   The category **icon**.
*   A **complexity badge** (SIMPLE, MODERATE or ADVANCED).
*   A **"System"** badge if the template is built into LibrePM.
*   **Name** and **description** (3-line preview).
*   **Badges for the required modules** (e.g., "planning"), if any.
*   The template **version** (e.g., "v1.0").
*   The **"Preview & Use"** button. You can also click anywhere on the card.

### Built-in Templates
LibrePM includes these system templates:

| Template | What it's for |
|----------|---------------|
| **Project Timeline** | Planning with Gantt chart, phases and dependencies |
| **Project Tracking** | Task management with status workflow and dashboard |
| **Gantt Project** | WBS, dependencies, baseline and critical path |
| **Event Marketing Timeline** | Planning marketing events: launches, conferences, campaigns |
| **Nonprofit Grant Project** | Budget, restricted funds, deliverables and reporting periods |
| **Public Call Application** | Call registry, eligibility checklist and submission package |
| **Sponsored Initiative** | Sponsor commitments, stakeholder map and evidence tracking |
| **R&D Consortium** | Partners, work packages, co-funding and deliverable register |
| **Agency Delivery** | Deliverables per client, budget per deliverable, timesheet |
| **Internal Operations Programme** | Portfolio overview, milestones and resource planning |
| **Portfolio Review Workspace** | Cross-project overview, aggregated risk and funding concentration |

## 🚀 Using a Template

Click **"Preview & Use"** on a card. The **"Use Template: name"** window opens:

### Left Column: Template Details
*   The template's **description**.
*   **Use Cases** and **Prerequisites**, when provided.
*   **What will be created**: a summary of the structure (number of phases, tasks, statuses, deliverables, dependencies, metrics).
*   The **complexity** and **version** badges.

### Right Column: Project Configuration
*   **Project Name \*** (required): pre-filled as "New Project - template name", you can change it.
*   **Description**: pre-filled with the template's description, editable.

### Creating the Project
1. Check or edit the name and description.
2. Click **"Create Project"** (rocket icon). While it's working, "Creating..." is shown.
3. LibrePM creates the project with the template's structure ready to go.
4. The new project becomes the **current project** and you are taken to the **Dashboard**.

Click **"Cancel"** to close without creating anything.

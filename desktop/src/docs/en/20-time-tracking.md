# Chapter 20: Time Tracking ⏱️

How long did "Write the quote" really take? The **Time Tracking** page helps you answer: you can time your work while you do it, or log the hours afterwards.

Every entry is linked to a **task** and adds up to its **actual effort**, so you can compare real time with the estimate (Chapter 3).

---

## 🧭 Opening the Page

Click **"Time Tracking"** in the sidebar.

The page works on the **active project** (the one you chose, for example, in the Planner or the Projects page). If no project is selected you'll see the message *"Select a project to track time"*.

The page is split into two side-by-side cards: **Timer** on the left and **Manual Entry** on the right. Below them you'll find the summary and the list of entries.

---

## ⏲️ The Timer

Perfect when you're about to start working on something.

1. In the **"Select Task..."** menu choose the project task you're working on.
2. Click **"Start"** (green button). The large stopwatch (format `00:00:00`) starts and turns green; while it runs you can't change task.
3. When you're done, click **"Stop & Save"** (red button).

LibrePM saves a timer entry with today's date, the description "Timer session" and the duration rounded to the **nearest minute** (minimum 1 minute). A notice confirms how many minutes were saved.

> **⚠️ Careful:** the timer only counts while you stay on this page. If you move to another page before clicking **"Stop & Save"**, the running session is lost and is not recorded.

> **💡 Note:** the Play ▶ button on Kanban cards (Chapter 3) starts a focus session, which is a separate thing: it does not create entries on this page.

---

## ✍️ Manual Entry

Forgot to start the timer? No problem.

1. Choose the task in the **"Select Task..."** menu.
2. Set the **date** (today by default).
3. Type the duration in **minutes** in the **"Minutes"** field (at least 1).
4. Optionally add a **"Description (optional)"** (e.g. "Review with the client").
5. Click **"Add Entry"**.

If the task is missing or the duration is not valid, a notice tells you.

---

## 📋 Summary and List

Below the two cards you'll find:
*   The **Total** badge, with the overall hours and minutes logged in the project (e.g. "Total: 3.5h (210 min)").
*   The number of **entries**.

The list groups entries **by day**, most recent first; next to each date there's the total minutes for that day. Each row shows:
*   An icon: ⏱️ stopwatch (green) for timer sessions, ✏️ pencil (light blue) for manual entries.
*   The **task title** and the description, if any.
*   The **duration** in minutes.
*   A **trash icon** to delete the entry (immediately, without confirmation).

The list shows the entries of the whole project. If there are none yet you'll read *"No time entries yet"*.

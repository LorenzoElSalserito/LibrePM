# Chapter 2: Boxes and Projects 📦

If LibrePM is your workshop, the **Project** is a box where you keep everything needed for a specific job (e.g., "Home Renovation", "School Project", "Summer Marketing").

Instead of having pieces scattered everywhere (and losing them!), each project has its **tasks** (things to do) and its **notes** inside.

---

## 🏗️ Let's Create the First Project!

### 1. Where to go?
Click on **"Projects"** in the menu on the left.

### 2. How to do it?
1. Top right, there is a blue button: **"+ New Project"**. Click it!
   *   If you don't have any project yet, you will also find a **"Create Project"** button in the middle of the page.
2. A small window (a "popup") will appear asking you two things:
    *   **Title**: Write a clear name (e.g., "Company Website"). It is required: while it is empty, the "Create" button stays disabled.
    *   **Description**: Explain what you need to do (e.g., "Redesign the company website"). It's optional, but it helps to remember.
3. Click on **"Create"** (or **"Cancel"** to give up).

🎉 **Hurray!** Your box is ready, and it automatically becomes the **current project** (the one shown by Planner, Kanban, Gantt and Calendar).

> **💡 Tip:** You can also create a project from the **Command Palette**: press **Ctrl+K** and, without typing anything in the search box, pick **"New Project"** from the initial list.

> **👥 Who can do what:** whoever creates the project is its **OWNER**. Other members can be **EDITOR** (they can make changes) or **VIEWER** (read-only). See Chapter 6.

---

## 🎨 The Color of Health

LibrePM immediately shows you if a project is going well or badly, coloring the edge of its box. It's like a traffic light!

*   **No colored border (OK)**: All good! There are no overdue tasks.
*   **🟡 Yellow border (WARNING)**: Watch out! There are some overdue tasks (1 to 3).
*   **🔴 Red border (CRITICAL)**: Alarm! There are more than 3 overdue tasks. The progress bar turns red too. Act now!

A task is "overdue" when its deadline has passed and it is not in the DONE status.

### What does the project card show?
Each project card shows useful information at a glance:
*   **📝 Description**: The text you wrote when creating it.
*   **📋 Task progress**: A counter showing completed tasks out of the total (e.g., "3/10 Task").
*   **⚠️ Overdue count**: If there are overdue tasks, a red warning appears (e.g., "2 Late").
*   **📊 Progress bar**: A thin bar showing how many of the tasks have been completed.
*   **📁 Archive icon**: If the project is archived, the title appears struck through with an archive icon and the card is grey.

## 🚪 Open, Close, and Archive

### 1. Opening the Project
To get inside the box and see all the details, click the **"Open Project"** button at the bottom of the card (the button is disabled for archived projects). This opens the **Project Detail** window.

#### The Project Detail Window
This is a powerful window with **four tabs**:

*   **📝 Info**: Here you can edit the **Project Name** and **Description**. Click **"Save Changes"** when done.
*   **📒 Notes**: Shows the latest notes attached to the project. The **+** button creates a new project note on the fly (it opens in the Notes page); clicking a note opens it in the Notes page. If there are more than five notes, a **"See all"** link appears.
*   **👥 Team**: The **"Open Team Management"** button opens a window where you see the project **Members** with their role (and can remove anyone who is not the OWNER with the trash icon) and, in the **Add** tab, you can add a LibrePM user (**"Connect LibrePM User"**) or create a local user (**"Create Local User"**), choosing the **Role** (Editor or Viewer). Only the OWNER can add members.
*   **🧩 Modules**: Switches to enable or disable the project's feature modules: **Time Tracking**, **Planning**, **Finance** and **Grants & Stakeholders**. Click **"Save Changes"** to store your choice.

> **📌 Note:** In the current version the Modules settings are saved on the project, but all pages remain reachable from the sidebar anyway.

At the bottom of the window you'll find:
*   **🗑️ Delete** (red button, left): Permanently deletes the project (with confirmation).
*   **📦 Archive / Reopen** (grey button, left): Archive a finished project or reopen an archived one.
*   **➡️ Go to Planner** (green button, right): Makes the project current and jumps straight to the Planner view to start working on tasks.

### 2. Editing the Project
Wrong name? Click **"Open Project"**, stay on the **Info** tab, change the name or description and click **"Save Changes"**.

VIEWERs cannot edit the project.

### 3. Quick Actions from the Card
Each project card has a **three-dot menu** (⋮) in the top-right corner with quick actions:
*   **Archive** (or **Reopen** if already archived): Put the project in the attic without deleting it.
*   **Delete**: Remove the project permanently (with confirmation).

### 4. Archiving the Project
Finished the job? Don't throw it away! You can put it in the attic (**Archive**).
1. Click on the three dots (⋮).
2. Choose **"Archive"**.
The project will disappear from the main list, but it's not lost!

### 5. Reviewing old work
Want to see finished projects?
1. At the top of the Projects page, turn on the **"Show archived"** switch.
2. Now the list shows **only** archived projects: they are grey with a struck-through title so you know they are closed. Turn the switch off to go back to active projects.
3. If you want to reopen one, click the three dots and choose **"Reopen"**.

---

## 🗑️ Delete Forever (Caution!)
If you created a project by mistake and want to delete it permanently:
1. Click on the three dots (⋮).
2. Choose **"Delete"**.
3. It will ask for confirmation (**"Delete project?"**). If you confirm, **it will disappear forever** along with all its tasks and notes. Use with caution!

You can also delete from inside the **Project Detail** window using the red **"Delete"** button at the bottom left.

> **🔒 Note:** Only the project **OWNER** can delete it. If you are an EDITOR or VIEWER, the deletion is refused.

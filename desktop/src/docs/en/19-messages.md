# Chapter 19: Project Messages 💬

**Notes** (Chapter 5) are documents you write and reread calmly. Sometimes, though, you just need a quick line: "I uploaded the draft", "Meeting tomorrow at 10?".
That's what the **Messages** page is for: a shared conversation, one per project, visible to all its members.

> **📌 Messages and Notes are two different things.** A message is plain text in a project chat; a note is a Markdown document attached to a project or task, with a title and preview. Messages do not create notifications in the bell 🔔: notes do.

---

## 🧭 Opening Messages

Click **"Messages"** in the sidebar (second item, right below Dashboard).

At the top you'll find the title **"Messages"** with the line *"Conversations shared within the project."* and, on the right, a **project selector**.
*   Choose the project whose conversation you want to see.
*   Careful: the selector changes the **active project** for the whole app, so Planner, Kanban and the other pages will switch to that project too.
*   If you don't have any project yet, you'll see *"Select or create a project to get started."*

---

## 📜 Reading the Conversation

The central card shows the project's messages, from the **oldest at the top to the newest at the bottom**. Each message shows:
*   **Who wrote it**: **"You"** for your own messages; for other people's messages, the author's display name (or "Former member" if that user no longer exists).
*   **Date and time** it was sent.
*   The **text**, with the line breaks you typed.

If the conversation is empty you'll read *"No messages yet. Start the conversation."*

### Automatic refresh
The page checks for new messages on its own **every 10 seconds**. If you don't want to wait, click **"Refresh"**.

### Older messages
The conversation is shown in pages of **50 messages** at a time:
*   **"Older"**: loads the previous 50 messages (enabled only when the current page is full).
*   **"Newer"**: moves back towards the newest messages.

---

## ✍️ Writing a Message

At the bottom of the page there's the **"New message"** box:
1. Type the text (up to **4000 characters**; the counter at the bottom left shows how many you've used, e.g. "120/4000").
2. Click **"Send message"**. While sending, the button shows "Sending…".
3. The message appears at the bottom of the conversation and the view returns to the newest messages.

The button stays disabled while the text is empty. Messages are **plain text**: no Markdown, attachments or reactions, and once sent they **cannot be edited or deleted**.

---

## 🔐 Who Can Read and Write

Messages follow your role in the project (Chapter 6):

| Role | Read | Write |
|------|------|-------|
| **OWNER** | ✅ | ✅ |
| **ADMIN** | ✅ | ✅ |
| **EDITOR** | ✅ | ✅ |
| **VIEWER** | ✅ | ❌ |
| Not a member | ❌ | ❌ |

If you try something your role doesn't allow, a red notice appears at the top of the page with a **"Retry"** button.

> **💡 Tip:** Messages really shine when several people work on the **same shared database** (Chapter 21): each person, from their own computer, sees the same conversation.
